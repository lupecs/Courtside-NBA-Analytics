# Courtside — NBA Analytics

An end-to-end basketball analytics and machine learning platform exploring NBA team performance, historical trends, and game outcome predictions.

## Project Goals

- Collect and validate historical NBA game data.
- Explore relationships between team performance and game outcomes.
- Engineer meaningful basketball analytics features.
- Develop and evaluate machine learning models.
- Build an interactive web dashboard for exploring insights and predictions.

## Technology Stack

**Analytics & Backend**
- Python
- pandas
- NumPy
- scikit-learn
- FastAPI

**Frontend**
- React
- TypeScript
- Vite

**Quality & Development**
- pytest
- Git
- GitHub

## Project Structure

- `backend/` — Data processing, machine learning, and API.
- `frontend/` — Interactive web dashboard.
- `data/` — Raw and processed datasets.
- `notebooks/` — Exploratory data analysis.
- `reports/` — Analysis outputs and visualizations.
- `docs/` — Project documentation.

## Research Question

Can NBA game outcomes be predicted using team performance metrics such as shooting efficiency, rebounding, turnovers, and home-court advantage?
